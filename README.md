# Hi, I'm Dariusz.

I build open-source tools that connect systems and fit into the ecosystems people already use. I enjoy finding unexpected ways to make technologies work together, choosing the language that fits the problem.

A few things I'm building:

- **[django-ray](https://github.com/dariuszpanas/django-ray)** — Distributed task execution for Django, powered by Ray.
- **[YAGA](https://github.com/dariuszpanas/yaga)** — Repository conventions you can check locally and enforce in CI.
- **[pydantic-versions](https://github.com/dariuszpanas/pydantic-versions)** — Schema versioning and data migrations for Pydantic.
- **[iperf3-lib](https://github.com/dariuszpanas/iperf3-lib)** — Network benchmarking and analysis from Python.

More on the way, including Rust tools I'm preparing to open source.
